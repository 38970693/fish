### 本轮学到的（可复用）
- **整理类任务 = 状态核实 + 收敛入口**，不是再写一份新文档。先 grep 把旧文档标记全部证伪/证实，
  再决定哪些是真待办；新文档必须反向把老文档「归档化」并挂上指针，否则文档数只增不减。
- 统计代码规模别靠读文件数：node 脚本 + 正则一把梭最准（注意 bash 会吞 `\s`，
  用 `[ ]*` 或 ` *` 替代；`[A-Z_0-9]` 匹配不到小写带连字符的 id，如成就 id `first-blood`）。
- 代码内无真 TODO（只有测试注释与校验文案）—— 说明「有数据没渲染/有字段没接线」这类债
  已在前面几轮靠自检测试守住了，剩下的是**内容**债不是**接线**债。
