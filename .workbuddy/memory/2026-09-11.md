## 环境（补充 2 · PowerShell 工具的拦截，踩了才知道）

- PowerShell 工具**禁止 `cmd /c`**（"cmd.exe cannot be used from the PowerShell tool"）→ 一律写原生 cmdlet。
- **命令里出现 `%VAR%` 样式的 token 会被安全策略直接拦掉**：我用
  `git log --format="SUBJECT:%s%nBODY:%b"` 被 "cmd.exe %VAR% environment variable syntax" 拦下
  → **换不带 `%` 的写法**（`git log -1`）；批量删临时文件时若同一命令里也有 `%`，也会被连坐 → 拆成两条发。
- `Get-Content` **不加 `-Encoding utf8` 读 UTF-8 文件会乱码**，据此数行数也不准
  （`开发路线图.md` 实际 358 行，`(Get-Content).Count` 报 265）→ 读内容/数行优先用 **Read 工具**。
- `git commit -F <UTF-8 文件>` 提交中文 message 没问题（落库是正确 UTF-8，控制台乱码只是显示问题）。
  验证方法：`git log -1` 重定向到文件，再用 Read 工具看。
- `git commit -F /c/Users/...`（Git Bash 的 `/c/` 挂载路径）**读不到文件**（`could not read log file`），
  但 `cd /e/gitlab/fish` 是好的 → **给 git 传 Windows 正斜杠路径**（`C:/Users/...`）即可。

  挂在 `skills` 与 `ai` **之间**，保证 AI 读到的是当帧值。
- `world.ts`：碰撞前 `obstacles.filter(o => o.type !== 'SEAWEED')` —— 水草从「墙」变成「草丛」，
  仍留在 `state.obstacles` 里供渲染与掩体判定。

  而 `inCover` 是每帧重算的 → 清标记等于空操作，声呐从来没真正生效过。

## 写探针时新踩的两个坑（都很隐蔽）

- **气泡 timer 只有 45 帧（0.75s），采样晚了就只剩 `null`**：我等 900ms 才读「?」，
  读到 `null`，一度误判「愤怒清零了但没冒泡」→ 改成 **250ms 早采样 + 1.15s 复采样**看稳定性。
  **教训：断言「瞬时表现」必须按 timer 帧数倒推采样时机。**
- **玩家会把当诱饵的鱼吃了，追兵凭空消失**：探针借一条场上的鱼当追兵，
  贴脸场景（100px）下玩家体型占优 → 一口吞掉，`read()` 回来 `anger = -1`（找不到该 id）。
  症状像「AI 崩了」，其实是实验台自己塌了 → **给玩家 `biteCooldown = 9999` 让它闭嘴**，
  再给追兵 `biteCooldown / schoolSkillCooldown = 9999` 屏蔽反制技。
- 附带确认：**应用没有任何「存档恢复到渔场」的逻辑**（localStorage 只有成就 / `skillLevel` / 排行榜），
  `start.bat` 也无特殊 URL。
- 那两条「404 但 `page.on('response')` 抓不到」的幽灵报错 = **浏览器自动请求 `/favicon.ico`**
  （`index.html` 没有 favicon link）。favicon 请求不会作为 page response 暴露 → 无害，不是 bug。

### 这次的测法（可复用，已写进 `canvas-game-e2e-probe` skill §6-9）

- **单测：记录型 canvas context 指纹**。塞一个假 ctx，把所有绘制调用 + **样式属性赋值**
  （必须用 setter 记，颜色差异全靠它）串成字符串当指纹。两条断言：
  ① 同类别选项**两两不同**（抓「两个选项长得一样」）；
  ② 每个非「无」选项必须**画得比「渲染层未实现的选项」基准多**（抓「按钮在、纹样没有」）。
- ⚠️ **必须写 positive control 钉住测法本身有效**，否则「全绿」可能只是断言没威力。
  我第一版自检写成「未实现的指纹 == 『无』的指纹」，**跑起来是红的** ——
  因为 `pattern !== 'NONE'` 时外层还有 `clip()` + `globalAlpha=0.4` 留下痕迹。
  **真正会撞车的是「两个都没实现的选项」**，自检要按这个写。
- **e2e：真比像素**。缩略图 `toDataURL()` 去重；大预览用 `getImageData` 采**平均色**
  —— 动画预览的 dataURL 本来就每帧在变，「变了」不构成证据，得看**变成什么颜色**
  （选绿 → g>r；选红 → r>g 且 r>b）。皮肤那组实测 16 张里 distinct=15，
  少的那个正是 **DEFAULT（本鱼本色）与小丑鱼本色 `#fb923c` 撞色**，符合预期。
- **动画 canvas 首帧空白坑**：`canvas.width = w*dpr` 会清空画布，第一次上色要等第一个 rAF，
  于是「元素已挂载、选择器已命中但像素全透明」→ 探针读到 `px: 0` 误判成"没画东西"。
  两头都治：组件进 rAF **之前先同步画一帧**；探针首次采样前留 ~300ms。
- **探针流程坑**：面板要从**菜单**开 —— 一点「开始游戏」整个菜单卸载，「装扮我的鱼」按钮随之消失
  （第一版就挂在 `waiting for locator('button:has-text("装扮我的鱼"))` 超时）。
- 顺带确认：`waitUntil: 'networkidle'` 在有代理时可能永不 idle → 改用 `'load'` 更稳。
