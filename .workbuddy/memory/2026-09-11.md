## 环境（补充 2 · PowerShell 工具的拦截，踩了才知道）

- PowerShell 工具**禁止 `cmd /c`**（"cmd.exe cannot be used from the PowerShell tool"）→ 一律写原生 cmdlet。
- **命令里出现 `%VAR%` 样式的 token 会被安全策略直接拦掉**：我用
  `git log --format="SUBJECT:%s%nBODY:%b"` 被 "cmd.exe %VAR% environment variable syntax" 拦下
  → **换不带 `%` 的写法**（`git log -1`）；批量删临时文件时若同一命令里也有 `%`，也会被连坐 → 拆成两条发。
- `Get-Content` **不加 `-Encoding utf8` 读 UTF-8 文件会乱码**，据此数行数也不准
  （`开发路线图.md` 实际 358 行，`(Get-Content).Count` 报 265）→ 读内容/数行优先用 **Read 工具**。
- `git commit -F <UTF-8 文件>` 提交中文 message 没问题（落库是正确 UTF-8，控制台乱码只是显示问题）。
  验证方法：`git log -1` 重定向到文件，再用 Read 工具看。
