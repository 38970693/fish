## AI 鱼随机心境（feat 8fc876e，13 文件 / +1127 −13）

- 用户需求「AI鱼要随机状态」→ 澄清后选「**随机心境/行为状态**」：种族行为（config.behavior）写死，
  全场小丑鱼永远一个德性（一起慢游、见你就跑）。心境是**叠在种族行为之上的个体性格层**：
  出生按种族加权抽一次，之后每 10~30s（MOOD_REROLL_FRAMES）重抽，鱼群才「活着」换状态。
- 数据层 `src/data/moods.ts`：8 种心境（悠闲/警觉/胆怯/饥饿/好奇/群聚/瞌睡/狂躁），分两类：
  - **数值型**（悠闲/警觉/胆怯）：只改 speed/agility/perception 倍率，行为仍归种族管；
    **CALM 全 1 = 旧行为**，是向后兼容的地基。
  - **接管型**（瞌睡/好奇/群聚/饥饿/狂躁）：`MOOD_HANDLERS` 在种族行为**之前**分发，
    做出种族做不出的举动 —— 瞌睡被逼近惊醒转警觉、好奇保持 280px 围观、群聚往同类身边凑、
    饥饿让温顺鱼也开荤、狂躁无视体型见谁咬谁。
- 接线：
  - `spawn.ts`：`createEntity` 出生随机心境，第 4 参 `options { moodId }` 供测试钉住随机性；`moodTimer` 到期重抽。
  - `ai.ts`：速度/敏捷乘心境倍率；**`senseRangeSq()` 收口所有锁定距离**（不收口的话警觉的「看得远」是假的）；
    tickTimers 里心境到期重抽（`angerTimer>0` 交战不换，免得追到一半经系）。
  - `GameCanvas.tsx`：非悠闲的鱼左上角画 emoji 徽章（只画玩家 900px 内，满屏 emoji 就成噪声了）。

## 修复「有些鱼原地转圈圈」（fix，追/退边界停泊带）

- 用户报「有些鱼会原地转圈圈」。**根因**：好奇（280px）/群聚（90px）在「追」与「退」的边界两侧
  都是全推力分支，中间没有停泊带；转向是比例式（`turnToward` 每帧吃 `BASE_TURN_SPEED 0.5−r×0.002`
  ≈ 0.45 的角差），鱼在边界环上每几帧被抢一次方向盘 → 原地高频往返打转。
  **复现数字：900 帧穿越 280px 环 460 次。**
- **修法**（抄 squad 跟随的现成经验 `FOLLOW_DEADZONE=260`「落后多远才开始追（避免抖动）」）：
  - 好奇：加 `CURIOUS_PARK=380` 停泊带 —— 280~380 之间不追加推力、速度 ×0.85 滑停、
    转身面向玩家（「停下来盯着你看」）；<280 才退，滑出即被停泊带接住。
  - 群聚：`SOCIABLE_KEEP` 90→135，到位改「配对悬停」（减速滑停 + 面向同伴），
    不再「漂过去→穿过去→折返」。
  - 两个分支都补 `isIdle` 管理（停泊 true / 追退 false，别让埋伏的静止标记残留）。
- 回归测试 3 例（moods.test.ts「原地转圈回归」）：断言 = **边界环穿越次数 ≤2 + 收尾停泊
  （isIdle / 距离带）**。抖动时穿越数以十计、永不静止；长用例必须把 `moodTimer` 钉成 1e9，
  否则跑到 600~1800 帧时心境重抽（randomizeMood 掷骰子）污染断言。
- **真机探针 probe-mood-orbit.mjs 的实验台三坑（都实测踩过）**：
  ① 玩家必须钉死：speed=0 + `invulnerableTimer=99999` —— 鼠标世界点随相机微动会让玩家
     缓慢漂移把好奇鱼顶进退让区；陨石（`state.time % 1500` 定点刷）把原地玩家砸死 →
     GAME_OVER 冻结世界，后面观察窗全部作废；
  ② 测试鱼要清野场残留：`lureActive`（灯笼鱼）会让优先级 1 诱惑追逐压过心境，小鱼怼到
     大肉块身上（间距收敛 17px）；负 `speedBoostTimer`（减速/麻痹）让追逐慢到 0.4 倍；
  ③ clearField 挪到 +60000 的鱼会被 clampToMap 拉回地图边缘，长观察窗里野场重新热闹
     → 断言必须按 id 锁定测试对象。
- **断言用「角扫掠」而非路程**：陨石溅射推挤是有限向（<0.5 rad），绕圈是单调累积
  （每圈 ≥2π）—— 角扫掠对推挤免疫、对绕圈敏感。
- 终版真机结果：好奇 600→379 停泊（收尾 4s 路程 0.0px、扫掠 0.00 rad、isIdle）；
  群聚 213→87 配对悬停（0.0px / 0.00 rad）。全量 **295 例 / 20 文件**绿；tsc 干净；
  build 362.98 kB（gzip 114.94 kB）。
