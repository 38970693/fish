## 「卡住了」排查 + git 抢救（同一轮）

### 结论一：游戏没卡死，是死亡界面

Playwright 实测（`scripts/probe-stuck.mjs`）：开局 → 22s 后小丑鱼被吃 → 弹出「战斗失败」。
**复活 / 重试按钮都是好的**。

⚠️ 但我第一次测出「复活无效」是**测试脚本的锅**：死亡界面正文里有「已复活 0 次」，
`text=复活` 会匹配到那个 `<p>` 上，点了个空气。改成 `button:has-text("复活")` 后一次通过。
**教训：Playwright 的 `text=` 是子串匹配，点按钮一律用 `button:has-text()`。**

死亡快的原因：鼠标固定在屏幕中心 → 鱼基本原地不动 → 不觅食 → 8 秒新手保护一过就被路过的
大鱼吃掉。属正常玩法，不是 bug（想测久按 G 开无敌）。
