### A.1 表格口径

半径、生命、伤害、食物价值是配置基础值，不包含玩家初始化、升级、缩水、核心角色修正和临时技能。食物价值用于击杀奖励计算，但成长受当前玩家阶级上限约束。速度见后面的独立表。

## B. 成长与战斗公式

### B.1 出生与成长

设当前阶级为 `t`，基础半径为 `r0`，当前玩家等级为 `L`。

| 项目 | 公式 / 参数 |
| --- | --- |
| 初始体重与进化点 | `10t + 5` |
| 初始等级 | `floor((10t + 5) / 10) + 1` |
| 初始半径 | `r0 + 2t` |
| 玩家身体速度 | `配置速度倍率 × 1.5 × 1.2` |
| 一次普通成长后的等级 | 至少保留旧等级，再与 `floor(weight / 10) + 1` 比较；额外级数单独参与 |
| 正常每级半径增量 | 2，累计等级半径增量最多 `0.6r0` |
| 进化身体半径 | `r0 + min(max(0, L - 1) × 2, 0.6r0)` |
| 单次击杀成长 | `min(目标食物价值, max(1, t) × 30)` |
| 捕食治疗 | 目标原始食物价值 ×2，上限内；队员击杀时本体也获得一份 |
| 进化门槛 | T2：30；T3：100；T4：300，累计不扣费 |

成长使用统一入口同步体重、等级和半径。实际窄缝容量不足时会暂存半径成长，宽处每帧最多补约 0.5 半径。道具、出生初始化、缩水与附身可能使身体偏离仅按等级重建的公式。

### B.2 普通撕咬伤害

先计算以下量：

```text
体型因子 = clamp(攻击者半径 / 目标半径, 0.5, 2.0)
等级优势 = 1 + 0.15 × min(max(攻击者等级 - 目标等级, 0), 6)
基础撕咬 = 攻击者配置伤害 × 1.5 × 体型因子 × 等级优势
```

然后按条件继续乘：

| 条件 | 倍率 |
| --- | --- |
| 攻击者处于诱惑状态 | ×1.5 |
| 同等级攻击小丑鱼且自己不是小丑鱼 | ×1.4 |
| 攻击者处于目标尾部背刺区 | ×1.5 |
| 目标处于易伤标记 | ×2 |
| 目标处于护盾 | ×0.3 |
| 目标处于无敌帧 / 玩家无敌模式 | 实际伤害为 0 |

背刺角度按攻击者相对目标朝向偏离大于 `0.67π`（约 120.6°）判断。前方可咬半角为 60°；攻击者自己的后弧也保留可达判定，但它不是背刺的定义。

实际碰撞循环先要求双方身体接触。HUD 的“检测范围 450px”及碰撞函数中的远距阈值，不代表实际拥有 450 距离的普通攻击。

## C. 全技能实际效果

### C.1 统一口径

下面 `P = 1 + 系统技能等级 ×0.1`，`D = 施法者配置伤害`，`R = 施法者实际半径`。默认系统技能 Lv.1 时 `P=1.1`。距离都是游戏坐标单位，秒数是逻辑时间。

大部分范围技能只处理有效范围内、不被实体障碍遮挡的敌对生物，并排除友军和吉祥物。它们不是鼠标点选技能。部分特殊实现没有完全复用同一套目标过滤，见 G 节。

右键技能玩家 Lv.3 解锁，冷却为：

`round(max(60, 180 - 系统技能等级 ×10) × 当前生态区右键冷却倍率)` 帧。

默认系统 Lv.1 时通常 170 帧 ≈2.83 秒；珊瑚区 85 帧 ≈1.42 秒。最高减冷却后，普通区域最低 1 秒，珊瑚区域最低约 0.5 秒。Q 固定 300 帧 =5 秒，当前不吃珊瑚冷却减半。

有限世界名义尺寸 6000；总实体预算 300；普通道具配置预算 40（部分掉落事件不严格共用相同限额）。争霸临近事件会预留 20 个实体位置；无限世界的背景生成上限约为对应预算的一半，不代表全部系统绝不超过此数。

有限小地图显示鱼的邻域距离约 2000，背景是全塘轮廓；无限雷达邻域为 3600。附带扩展投影支持 1.35 倍范围，但主界面目前没有独立扩大地图按钮。

| `happy-fish.renderer` | 由有效渲染器 URL 选择写入 |

音乐静音当前为模块内会话状态，没有对应本地保存入口。当前对局与无限探索记录也没有持久化键。

排行榜记录规则：死亡 / 手动胜利时写入；同一局 upsert；全局按分数保留十条，再供界面筛塘。模式与规则版本存在记录里，但当前界面没有完整的独立模式 / 版本筛选体验。

## H. 复现入口与核对范围

### H.1 开发环境入口

已有开发服务器时直接打开；未运行时在仓库执行 `npm run dev`，默认端口 3000。以下 URL 是本地复现入口：

| 目的 | URL |
| --- | --- |
| 普通有限世界 | `http://localhost:3000/?mode=LEGACY&world=FINITE` |
| 普通无限世界、固定种子 | `http://localhost:3000/?mode=LEGACY&world=ENDLESS&worldSeed=42` |
| 争霸经典布局 | `http://localhost:3000/?mode=RIVALS&world=FINITE&pondLayout=CLASSIC` |
| 争霸程序化布局 | `http://localhost:3000/?mode=RIVALS&world=FINITE&pondLayout=PROCEDURAL&pondSeed=42` |
| 选择 Canvas 路径 | 在相应 URL 增加 `&renderer=canvas` |
| 请求 Pixi 路径 | 在相应 URL 增加 `&renderer=pixi`；可用性不足时仍可能回退 |

菜单选择世界形式可覆盖当前开局选项。URL 不直接替代所有菜单操作。渲染器选择由运行环境决定，当前 `App` 把开发环境标志传给 Pixi 可用性入口，因此不能直接宣称生产包始终默认使用 Pixi。

`worldSeed` / `pondSeed` 是布局重放参数；动态生物和事件仍有随机过程。对战实验虽然有代码入口，但当前菜单未提供独立可见按钮，不列为正常玩家开局模式。
