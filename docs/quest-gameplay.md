# 冒险任务玩法

游玩路线调整为：**完成小目标 → 领取奖励 → 开启下一章 → 成长和进化 → 持续远航委托**。

每章同时开放三个任务，玩家可以自行选择顺序。右侧任务卡显示条件、实时进度、操作提示和奖励；完成后直接到账，不需要额外领取。

| 章节 | 任务 | 完成条件 | 奖励 |
| --- | --- | --- | --- |
| 小鱼出发 | 开饭啦 | 吃掉 3 只小生物 | 成长 +4、积分 +20 |
| 小鱼出发 | 逛逛新家 | 实际游动累计 600 米 | 积分 +30、恢复 15% 生命 |
| 小鱼出发 | 小尾巴冲冲 | 游动时累计加速 2 秒，可分次完成 | 成长 +3、5 秒护盾 |
| 寻宝小队 | 口袋里的宝贝 | 拾取 3 次道具、金币或宝藏 | 成长 +5、积分 +40 |
| 寻宝小队 | 一起去冒险 | 累计收编 3 位伙伴 | 恢复 25% 生命、6 秒护盾 |
| 寻宝小队 | 露一小手 | 成功释放技能 2 次，右键或 Q 都算 | 成长 +5、积分 +40 |

| 海洋探险家 | 长大一点点 | 比开局提升 3 级 | 成长 +6、积分 +60 |

完成一章的三个任务，额外获得阶段礼包：

- 小鱼出发：成长 +4、积分 +40。
- 寻宝小队：成长 +6、积分 +60。
- 海洋探险家：成长 +8、积分 +100、8 秒护盾。

主线合计提供 49 成长与 530 积分，分散在多个行动和章节中发放。成长沿用现有体重、等级、进化点和体型同步规则，积分沿用现有计分系统。

## 远航委托

主线完成后，每轮提供三个新目标：再进食 8 只、再游动 1200 米，以及轮流出现的「再拾取 3 次」或「再释放 3 次技能」。全部完成后奖励积分 +100 和恢复 20% 生命，自动开始下一轮。

每轮从开启时的统计值计数，旧行动不能反复领奖；目标难度保持有上限，长时间游玩也能继续完成。

## 进度规则

- 普通鱼塘和无尽海域默认开启。实验对战模式不发任务奖励。
- 主线按本局累计，提前完成的探索、拾取等行动在后续章节解锁时仍有效。
- 换塘、进化、附身和复活保留进度；重新开始一局重置任务。
- 只统计玩家自己的进食和技能；金币、道具与宝藏均计拾取，破岩提示不计。
- 里程来自实际位移，传送、附身及无尽海域的原点平移不能刷进度；原地按空格也不计加速时长。
- 每个任务及阶段礼包只奖励一次，奖励不能救活已遭受致命伤害的玩家。
- 治疗不超过生命上限，任务护盾不会缩短原有的更长护盾。

配置位于 `src/data/quests.ts`，奖励结算位于 `src/systems/quests.ts`，界面位于 `src/components/QuestTracker.tsx`。
