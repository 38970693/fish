# 四分钟短局竞技：首轮可玩版本

日期：2026-10-01。模式 `ARENA`，规则版本 2。对应[升级设计草案](short-match-evolution-design.md)的第一轮对局闭环，并纳入“鱼挤在一起、目标不清楚”的首轮反馈；草案中的随机突变、羁绊、秘宝和新操作尚未实现。

## 进入方式

运行 `npm run dev`，在菜单点击 **“四分钟短局竞技 · 1 人 + 5 AI”**。也可使用 `?mode=ARENA`；正式开始仍需点击短局按钮。

入口强制使用有限清水地图和小丑鱼 T1 身体，不受普通菜单的高阶鱼种、海域和无限开关影响。系统技能等级从 1 开始，不继承本地技能等级。普通开始按钮继续进入普通或既有争霸玩法。

## 本轮规则

| 内容 | 已实现行为 |
| --- | --- |
| 参赛者 | 1 位玩家 + 5 位 AI；中立磷虾不计入存活参赛人数 |
| 初始资源 | 每位同生命、速度、体型、Lv.2、15 成长、满体力及 8 秒保护；各自资源互不共享 |
| 地图 | 中心固定、活动半径 900；四组小岩礁与外侧水草，中心和出生路线留空 |
| 移动 | 鼠标转向，空格冲刺；持续前游、体力消耗与恢复沿用现有控制器 |
| 捕食 | 接触自动尝试撕咬；敌对同种可互咬，允许越级致死，保留残血吞噬、绕后和预告反击 |
| 成长 | 出生 Lv.2，每增加 12 成长升一级，最高 Lv.12；减少食物后同步下调成长门槛，沿用升级体型增长与体型上限 |
| 身体与技能 | 本轮保持小丑鱼身体；Lv.3 起右键本体技能，Q 随等级切换到已解锁最高档 |
| AI | 独立选择食物、可见弱敌、避开强敌和返回安全区；移动、体力、技能与状态计时复用玩家系统 |
| 食物 | 每个出生点尝试初铺 6 份，距出生鱼 100～260；每秒最多补 2 份，四阶段上限依次 36／24／16／8；食物间至少 90，补刷避开参赛者与实体地形。每秒清掉圈外和超过阶段预算的食物，不计奖励 |
| 竞技分 | 吃中立食物按配置价值加分；淘汰参赛者加 50，另记录淘汰数和对参赛者的有效伤害 |
| 有效伤害 | 只记真实扣除的生命，排除无敌与溢出伤害，护盾减伤后计算；同一死亡只结算一次 |
| 队伍与续命 | 本模式不收编、不附身、不手动复活，淘汰后立即结算 |
| 练习 | G 无敌或 P 自动驾驶会粘性标记练习，关掉后仍保留标记 |
| 记录 | 展示本局六人排名，不写入冒险排行榜；暂未新增竞技历史榜 |

采用统一浅滩效果，不把现有地图四象限中仅玩家接入的沼泽腐蚀带进竞技。没有自然 Boss、建筑升级、跨塘、冒险任务奖励、旧随机宝藏或旧投食敌队。保留旧模式的执行系统与入口。

## 缩圈与胜负

有效时钟只在游玩时推进。一局上限 240 秒，停止或结算后时钟冻结。

| 时点 | 动作 |
| --- | --- |
| 0 秒 | 安全区半径 900 |
| 35 秒 | 首轮预告，黄色虚线显示下一安全区 |
| 45～55 秒 | 线性缩到 675 |
| 110 秒 | 第二轮预告 |
| 120～130 秒 | 线性缩到 450 |
| 170 秒 | 决赛区预告 |
| 180～190 秒 | 线性缩到 225 |
| 240 秒 | 仍有多人存活则到时排名 |

圈外每秒伤害为最大生命的 `4% + 当前缩圈阶段 ×3%`，第一、二、三轮分别为 7%、10%、13%；每帧结算，玩家和 AI 相同，统一受无敌、护盾等规则影响。HUD、场景圆环和雷达读取同一安全区半径。

只剩一位存活者时立即结束。存活者优先；到时存活者依次按竞技分、有效伤害排名，相同条件并列。已淘汰者按淘汰时点排列，同帧淘汰并列；同帧全灭不会由遍历顺序产生获胜者。玩家提前淘汰时立即展示当前对局排名，不等待 AI 完成剩余对局。

## 画面与验证

HUD 顶栏只显示时间、存活人数和当前名次／分数；单一目标卡按“成长 → 争分 → 决赛”推进。开局显示 12 成长解锁技能的进度，优先提示可直达的最近食物；圈外或下一圈外优先提示回圈，隐藏食物不作为导航目标。屏内目标只用一个浅绿环，屏外显示一个方向箭头。生命、体力与技能放在左下，雷达缩小且窄屏隐藏；不把窄屏排版检查等同于触屏操控已支持。

短局移除普通海底纯装饰，实际四组岩石与水草仍参与玩法。参赛者仅在距玩家 300 内显示姓名描边，雷达遵守当前感知规则；AI 同帧选择食物时降低已被其他 AI 选中食物的优先级，减少五个对手同时扎向一份食物。Canvas 与 Pixi 共用同一个覆盖层与规则结果。

普通／争霸／无尽自然刷鱼同步增加实体间至少 50 的边缘间距，240 半径内最多 7 个存活生物；争霸附近目标从 60 降为 24，自然补刷活体上限为 120（已有阵营的队员／敌队不计）。全局硬上限仍为 300，脚本事件自行管理其预算。自然野生鱼只与 300 范围内最多 6 个邻居聚群，提前分离；脚本实体保留原群游规则。旧局已有鱼不会因这个自然补刷上限被直接删除，重开可立即看到完整的新分布。

专项测试覆盖统一开局、旧模式隔离、同种互咬、成长曲线、伤害归属、AI 技能、一次结算、缩圈、暂停、提前结束与并列排名。另有三个种子从出生通过正常逻辑自然推进到淘汰或到时，不跳时钟或强制修改生命；这是自动模拟，不替代真人体验验证。

浏览器专项在 Canvas 和 Pixi 两种渲染器验证菜单入口、鼠标与冲刺、缩圈预告、淘汰、无复活按钮、立即再战、到时胜利以及返回旧玩法。结算边界用受控夹具加速，不能视为四分钟真人实战。

首轮曾运行全量测试：836 项通过、1 项失败。失败为现有任务清单已记录的 `g1-fixed-encounter` 撤退队形差 7px、断言阈值 2px；本次未改该断言或旧撤退逻辑。最终短局专项及类型检查、构建结果见交付说明与任务清单。

版本 1 检查：21 项短局专项通过；Canvas／Pixi 两条浏览器流程通过；类型检查与生产构建通过。战斗修正后另跑短局、旧稳定战斗与玩家成长共 48 项，通过。成长曲线调整时还跑过七文件 108 项回归，通过；记录按各次实际运行报告，不将不同时间的结果合并成一次全量通过。

版本 2 减密度检查：七文件 67 项专项通过（短局 25、自然间距 3、小景 4、附近补刷 4、群游 5、鱼塘 14、敌队 12）；Canvas／Pixi 两条浏览器流程均覆盖桌面和 390×844 窄屏并通过；类型检查与构建通过。最终全量 **848／849 通过**，未通过项仍在 `g1-fixed-encounter`，此次是“原地守候无伤”的场景前提（实际剩血 67.7%，断言 100%），与初版的 7px 断言不是同一失败，不将两者混称。自然生成筛选和随机数消费发生变化，旧固定台架需要单独核查；本轮保留原断言，不宣称全量或 G1 放行。

`scripts/probe-game-readability.mjs` 在正常入口游动并采图，未改生命、无敌或时钟：本次普通模式 8 秒后阵亡，场上 120、距玩家 500 内 6；争霸约 12.15 秒仍在游玩，场上 120、附近 3。样本未固定随机性，仅用于发现视觉和运行错误，不能推出难度、公平性或典型密度。两次均无 Pixi 渲染异常；截图在 `previews/readable-*-natural.png`，短局桌面／窄屏截图在 `previews/arena-readable-*.png`。
