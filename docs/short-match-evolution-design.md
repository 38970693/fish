# 2D 吞噬竞技与局内进化：升级设计草案

日期：2026-10-01。来源：用户提出的“2D 即时吞噬竞技 + 局内进化 Roguelike”方向，以及当前仓库的玩法与开发计划。

**文档状态：用户已授权开始开发，第一轮对局闭环已接入；完整升级方案仍未全部实现，也未证明比其他游戏更好玩。** 首轮实际范围见[四分钟短局竞技交付说明](arena-first-playable.md)。现有冒险规则见[完整玩法文档](../玩法文档.md)，现有数值见[图鉴与数值附录](gameplay-reference.md)。本文其余数值仍为设计建议，以交付说明区分已实现范围。

本文先把方向变成可试玩、可比较的规则。现有[开发任务清单](../开发任务清单.md)仍是实现任务的执行入口；这里的分阶段建议尚未加入执行队列。

## 1. 定位与体验目标

目标体验：**一眼识别威胁，迅速选择打法，通过操作制造机会，每局获得不同组合。** 首个原型围绕鼠标移动、空格冲刺和少量技能键展开，面向桌面浏览器。

用户提出的完整愿景包括进化分支、操作反杀、动态生态、随机突变、多人模式、外观商业化和赛季内容。首版重点验证以下四件事：

| 核心问题 | 玩家应能做到 | 怎样观察 |
| --- | --- | --- |
| 判断 | 看懂当前敌人是否能吞、是否危险，以及正在准备什么攻击 | 首次试玩能解释一次死亡和一次逃生 |
| 决策 | 在成长、抢宝、绕路和追击之间做取舍 | 相同种子下出现两条有理由的路线 |
| 操作 | 用转向、冲刺、急停和掩体躲反击、创造绕后窗口 | 成功反杀能追溯到具体动作 |
| 反馈 | 知道伤害来自哪里，组合何时触发，为什么胜负已定 | 结算可描述本局关键选择，而不只显示体重 |

“更好玩”作为验证目标，不作为承诺。增加模式和内容不能替代上述体验的试玩证据。

## 2. 当前基础与升级差距

| 用户方向 | 当前可复用基础 | 需要补充或重做的部分 |
| --- | --- | --- |
| 体型之外的胜负 | 稳定撕咬、生命、伤害、护盾、毒伤、背刺、反击预告 | 各伤害路径统一公平规则，分支代价与克制验证 |
| 进化分支 | 鱼种三选一、饮食与生态区影响候选 | 累积突变、组合触发、分支预算；不是简单换鱼种 |
| 操作深度 | 鼠标转向、冲刺、位移技能、绕后 | 急停、明确侧咬、主动尾击、冲刺吞噬窗口 |
| 动态生态 | 水草、礁缝、可破岩层、洋流、沉船、事件鱼群 | 洞穴路线、漩涡、毒雾、可交互珊瑚与统一事件调度 |
| 局内 Roguelike | 流派技能与宝藏；已有九特性设计计划 | 随机选项实际获取、持续保留、羁绊、逆袭资源 |
| 3～5 分钟竞技 | 对局时钟、AI 敌队、资源争夺 | 短局规则、明确结束条件、缩圈、统一开局与成长节奏 |
| 团队与合作 | AI 队员、集火／护卫／撤退、附身 | 真人队伍、房间、同步、合作目标、配合与断线规则 |
| 清晰 2D 反馈 | Canvas / Pixi、粒子、合成音效、HUD、雷达 | 风险提示口径、预告层级、反杀播报、可关闭震动与顿帧 |
| 长期成长 | 本地成就、排行榜、装扮、部分特产记录 | 完整收藏树、赛季、公会、账户与跨设备保存 |
| 技术体验 | 本地立即开局、LOD、实体预算与性能探针 | 明确目标设备、正式性能验收；联网能力需另行建设 |

当前 Q 技能随等级换成最高档，较早的技能不会组成可自由搭配的技能组；商场已是免费外观面板。新设计须分别处理“技能操作”和“被动突变”，避免把已有功能误当作新组合系统已经完成。

## 3. 首版范围与既有模式的关系

### 3.1 建议的首个可玩版本

先做一个独立的**短局竞技实验模式**：有限地图，1 位玩家 + 5 位 AI 参赛者，固定低阶开局，一局最多 240 秒有效游玩时间，包含缩圈、三个构筑方向、九种突变和一个羁绊。

地图另有中立食物和少量野鱼。参赛者与中立生物有独立身份，吃掉最后一条野鱼不会决定胜利。AI 参赛者采用相同成长、技能、资源和伤害规则，不能暗中获得额外视野或免费升级。

AI 的突变候选遵循相同抽取与冲突约束，在合法候选中按自身构筑策略选择；无敌保护、技能冷却和掉落领取也统一处理。预设组合只用于构筑验证台架，不成为正式局中 AI 免费拥有的能力。

首版按下表处理现有机制，具体入口名称在实现时确定：

| 事项 | 短局原型建议 | 原因 |
| --- | --- | --- |
| 普通与现有争霸模式 | 保留现有入口，新增显式实验入口 | 现有争霸计划目标为 12～15 分钟，不直接缩成四分钟 |
| 世界形式 | 仅有限地图 | 缩圈和有限路径需要统一边界 |
| 初始鱼种 | 固定 T1 身体、相同初始属性 | 当前可选 T3 开局会破坏起跑线 |
| 系统技能等级 | 每局从同一值开始，忽略旧局属性存档 | 当前漂流瓶可能保存技能等级，竞技不能继承优势 |
| 战队与附身 | 本模式首版关闭收编、主动附身与自动夺舍 | 一次生命、六位参赛者的胜负更易解释 |
| 手动复活 | 正式局无复活；练习另开入口 | 避免淘汰与无限续命冲突 |
| 挂机与无敌 | 仅练习使用，记录独立 | 正式排名不受辅助功能影响 |
| 自然 BOSS | 首版不生成；击杀 BOSS 不使用旧通关条件 | 竞技结束由参赛状态与时限决定 |
| 跨塘、建筑与任务 | 首版无跨塘及商场暂停；冒险任务不注入竞技奖励 | 缩圈节奏与公平资源需要独立控制 |
| 外观 | 可使用纯外观选择，危险标记绘制在外观上方 | 皮肤不能遮盖判定或改变实际属性 |

真人多人、3v3、合作 Boss、排位、UGC、赛季、公会和商业化保留为后续方向。联机版本还需要重新设计暂停、同步、输入校验与重连，不能直接把本地状态发出去当成完整方案。

### 3.2 一局流程与胜负

| 有效游玩时间 | 主要机会 | 地图压力 |
| --- | --- | --- |
| 0～45 秒 | 熟悉方向、吃小食物，争取第一个突变 | 初始安全区；出生点均有基础食物与可退出路径 |
| 45～120 秒 | 首次秘宝争夺，第二次构筑选择，形成强项 | 第一次收缩，提前 10 秒预告 |
| 120～180 秒 | 第二次争夺，组合成型，利用路线分离敌人 | 第二次收缩，部分外围资源移出安全区 |
| 180～240 秒 | 决赛区交锋，明确领先者与反杀窗口 | 最终区域，持续增强圈外压力 |

建议以地图可活动半径的 100% → 75% → 50% → 25% 作为初始缩圈梯度。具体半径、收缩速度和圈外伤害须根据赶路时间验证；每次收缩须保留连通的撤离路线，不能把安全区放在不可达岩层里。

只剩一位存活参赛者时立即结算。240 秒仍有多位存活时，依次按竞技分、对参赛者造成的有效伤害排序；完全相同允许并列名次。存活者排在已淘汰者前，已淘汰者按淘汰时点排序，同帧淘汰并列。所有人同帧阵亡时，按该帧统一结算，不能由遍历顺序选赢家。

竞技分建议独立计算：中立食物按配置价值计分；秘宝拾取奖励 20；淘汰参赛者奖励 50。掉落资源与淘汰奖励分别记账，各自只能领取一次。此分数不套用现有鱼塘积分倍率，也不沿用探索建筑的送分机制。有效伤害只记真实扣除的生命，不记无敌伤害和溢出伤害。

“3～5 分钟”指完整对局的目标节奏。玩家可能提前阵亡，此时展示即时结算并提供立即重开；不以失败时长冒充完整局长，也不要求死亡后等到四分钟。

单人原型选突变时暂停世界，界面同时说明计时暂停；240 秒不含选择用时。多人阶段改为不中断世界的限时选择，并制定超时选项，不能继承单人全局暂停。

## 4. 成长：身体、突变和技能各司其职

### 4.1 三层成长

| 层次 | 玩家获得什么 | 建议约束 |
| --- | --- | --- |
| 等级与身体 | 基础体型、生命及身体技能 | 主要来自捕食；增幅有限，保留小鱼操作空间 |
| 局内突变 | 持续保留的战术特性 | Lv.3、6、9、12 各三选一，最多 4 个不同突变 |
| 秘宝 | 构筑补全或一次局势机会 | 地图争夺取得，效果明确，不能无限叠加 |

用户提出“进化点自由分配”。建议先在原型中用**一份成长预算选择一个突变**表达分配，再验证是否值得加入可任意加点的面板。这样先回答速度、毒、控制和防护是否产生不同玩法。

若后续加入自由加点，进化点须拆成“累计进化进度”和“可消费突变点”，明确赚取、消费、重置与面板提示。当前进化点是不扣费的累计门槛，不能直接改成扣费余额，否则会出现升级后反而失去进化资格的歧义。

短局成长曲线独立配置，不直接沿用 T1→T2 的 30、T2→T3 的 100、T3→T4 的 300 门槛。首轮希望正常参与资源争夺的玩家约在 30、90、150 秒获得前三次选择；这是需要试玩调整的目标，不是按时间免费升级。

### 4.2 三个构筑方向与九种候选

下面每个方向三种突变，共九种。先测试代表效果，再接随机抽取；所有数值作为起始调参值。

| 方向 | 突变 | 建议效果 | 代价或对手的应对 |
| --- | --- | --- | --- |
| 机动 | 轻鳍 | 常速 +12%，最大生命 -10% | 被控住或困在角落更危险 |
| 机动 | 滑行 | 冲刺体力消耗 -15%，冲刺结束后短暂减速 | 用耐力换移动窗口，不能无限追击 |
| 机动 | 尾击 | 获得主动尾击，后方命中推开目标，冷却 6 秒 | 无强杀伤，正面压迫可避免其收益 |
| 毒控 | 毒牙 | 普通咬命中施毒 3 秒，每秒目标最大生命 1.5% | 需先接触；不叠层、不因多次攻击无限延长 |
| 毒控 | 冷鳍 | 主动技能命中减速 25%、持续 0.8 秒，同目标冷却 4 秒 | 不叠加为硬定身，留出逃生输入 |
| 毒控 | 电鳍 | 主动技能命中产生一次小范围电伤，同目标冷却 4 秒 | 有明确电弧预告；位置分散可减收益 |
| 防护 | 厚鳞 | 最大生命 +20%，常速 -8% | 血量优势有赶路与追击代价 |
| 防护 | 护膜 | 主动启动 1 秒、减伤 50%，冷却 8 秒 | 看准爆发时点；过早开盾可被拉扯 |
| 防护 | 吸血 | 对参赛者造成直接有效伤害的 8% 回血 | 食物、圈伤、毒与电弧不回血，避免自循环 |

首版暂不开放分裂、召唤和反伤：这些机制分别增加实体、击杀归属和递归伤害复杂度。它们仍属于用户方向中的后续候选，不表示从长期计划删除。

主动键建议：鼠标方向、空格冲刺、Shift 急停、右键身体技、Q 当前流派技、F 突变主动技、E 地图互动。最多装备一个突变主动技；已获得尾击后不再抽到护膜，反之亦然。九种突变中的被动效果持续存在，Q 的既有最高档更替规则暂时保留。具体键位需试玩确认并提供可改键入口。

### 4.3 随机三选一

- 候选按本局种子生成，开面板即固定；重开面板和重复点击不能换牌或重复领取。
- 排除已获得项、主动槽冲突项和当前身体无法使用的项；候选中至少一个能立即产生作用，至少两个方向可选。
- 由低阶开局跨过多个门槛时，逐次排队选择，不能丢掉中间奖励。
- 选择、身体进化、死亡和对局结束同帧冲突时，死亡／结束先结算，暂停选择不复活玩家。
- 选项直述效果与代价，并预览对现有组合的影响；不把内部标签或倍率计算推给玩家。

## 5. 克制与反杀：靠窗口形成优势

“速度克毒、毒克坦克、坦克克速度”是待验证的关系，不应直接写成碰到某流派就加伤害的隐藏规则。

| 对抗 | 预期成立的原因 | 不成立时应查什么 |
| --- | --- | --- |
| 机动对毒控 | 更易脱离施毒距离，利用较短状态时间重新进场 | 施毒范围是否过大，持续时间是否过长，地形是否无出口 |
| 毒控对防护 | 持续比例伤害迫使慢速身体主动换位 | 护膜是否同时清毒，恢复是否抵消全部持续伤害 |
| 防护对机动 | 扛过突进窗口，靠预告反击迫使对方撤退 | 反击是否无法命中，盾是否总被自动开启或窗口太窄 |

任何方向都要有可以识别、可以操作的应对，混搭也应可行。试玩前不预设胜率结论；若一种突变在各种位置、对手和阶段均优于其他项，先修收益和代价。

### 5.1 普通战斗的建议口径

1. 同阵营不伤害；敌对参赛者即使同鱼种也能互咬。现有“同种不互咬”规则在此模式需要显式覆盖。
2. 体型比提供有上限的伤害优势；取消普通咬对高等级目标的不可致死门槛，所有伤害统一经过生命、护盾、无敌与归属结算。
3. 正面咬伤害稳定，侧咬降低收益，绕到尾部获得背刺增益；HUD 给明确的命中和方向反馈。
4. 普通吞噬保留“目标残血 + 自己身体足够大”的直觉，建议沿用生命 ≤30%、自身半径不小于目标作为第一轮条件。
5. 冲刺吞噬建议要求实际碰撞、朝向正确、冲刺开始后 0.25 秒内命中、目标生命 ≤20%。不因一直按空格而永久拥有强化吞噬；相同接触不能同时重复结算咬伤与吞噬。
6. 反击采用范围与时间预告，不在无提示的随机帧秒杀。玩家和 AI 使用相同命中检测，毒伤与召唤等后续效果必须保存伤害来源。

具体侧咬倍率、背刺角度和冲刺伤害先用独立配置实验，不在这里宣称已经平衡。

### 5.2 急停、尾击与假动作

急停建议为短按 Shift：速度降至常速的 20%，持续 0.3 秒，消耗 15 冲刺体力，冷却 1 秒。停止期间还能转向，结束后恢复前进；体力不足时给失败提示，不能无限连按驻留原地。

尾击是构筑获得的后方推开动作，不再给全部鱼额外配置一个常驻技能。假动作由转向、短冲和急停组合产生，无须增加“假动作按钮”。先验证急停带来的摆脱与重新对齐，再决定是否需要更多输入。

## 6. 地图与动态生态

首张竞技地图建议包含三类彼此连通的空间：有食物的安全边路、带洋流的转场路线、较开阔的秘宝争夺区。每个争夺点至少两条进出路线；出生保护不允许在永久食物源上无限安全成长。

| 元素 | 首版处理 | 玩家决策 |
| --- | --- | --- |
| 食物与小鱼群 | 基础成长资源，外围分散，少量迁徙进入冲突区 | 稳定成长或冒险抢高价值资源 |
| 水草 | 复用掩体，增加进入／暴露提示 | 断追击、埋伏；仍可被探测与范围攻击应对 |
| 岩礁与窄缝 | 复用通行半径约束；两端可出 | 大身体换正面优势，小身体换路线优势 |
| 洋流 | 同时影响参赛者与野鱼，清楚显示方向 | 借流撤退，判断逆流追击成本 |
| 可破岩层 | 首版复用已有冲刺破岩，调整奖励到竞技资源 | 暴露位置换捷径或资源 |
| 秘宝点 | 预告、位置与争夺时间统一显示 | 赶场、绕后、放弃；不同时弹过多事件 |
| 沉船 | 后续短局地图变体再加；已有探索玩法保留 | 交互时暴露与获利的取舍 |
| 漩涡、毒雾、洞穴、撞珊瑚碎片 | 第二张地图再验证，每次只加入一个新因素 | 先确保效应、出口与收益可读 |

生态区改变环境和路线，不叠加大量隐形属性。圈伤、沼泽伤害和毒雾采用不同图标与来源提示；窄缝成长暂存和身体进化延迟要继续给玩家可解释提示。

事件调度优先级建议：结算 > 缩圈预告 > 秘宝争夺 > 小生态事件。秘宝位置必须合法、可达，不能在收缩结束后立即消失的区域；失败则换候选或延后，不把物品塞进障碍。

## 7. 秘宝、羁绊与逆袭资源

### 7.1 一个羁绊先验证

首版只验证“毒牙 + 电鳍”：电鳍命中带有自己毒状态的目标时，触发额外电弧，附近敌人减速 40%、持续 0.6 秒；同施法者该组合冷却 6 秒。

触发需实际命中，有醒目的毒电合并图标与短音效。电弧不再次触发电鳍、吸血或自己，单次结算不递归。首版不用零速度麻痹，避免控制叠加导致完全无法操作；如果后续增加硬控，需要独立免控窗口。

秘宝建议首版只保留两类：一类提供一个合法的构筑候选，另一类提供一次带代价的逆袭机会。掉落内容受当前背包与冲突规则约束，满槽时不能无提示丢弃。

### 7.2 逆袭秘宝

逆袭资源要通过去危险地点争夺获得。建议在第二场争夺出现一枚“破甲珍珠”：所有人可抢，只有等级低于当前最高存活参赛者至少 2 级者可激活。

激活后显示明确光环，8 秒内下一次有效背刺增加额外伤害，额外伤害上限为目标最大生命的 20%；命中即消耗。它不赋予无敌、不直接处决、不取消目标闪避和护盾，也不能由领先者交给队友反复使用。

若领先者拾取，则兑换同价值的普通成长资源，不能获得逆袭效果。这样仍有抢点意义。进入激活条件、拾取、转化和失效都给提示；不在玩家残血时凭空生成一件隐藏保底神器。

必须测试它是否给落后者一次操作机会，且没有变成“故意不升级更强”的最优策略。条件阈值和伤害上限需要依据试玩调整。

## 8. 2D 信息与操作反馈

### 8.1 危险标记

绿色表示**当前满足残血吞噬条件且保护状态允许**，红色表示明显危险，黄色表示可战但有风险，金色表示秘宝，灰色表示地形。颜色只是冗余信息，同时使用可吞图标、盾牌、等级差与攻击预告，不能只靠红绿区分。

不要把绿色定义为“接近必胜”：血量、技能和第三方干预仍会改变战况。不可感知的敌人不显示精确血量或构筑，避免 UI 破坏隐蔽玩法。被揭露后再显示已知信息。

皮肤不改变命中半径与属性；实际判定不能跟随夸张尾巴和饰品。轮廓、身份与风险标记要在拥挤环境下仍可辨识，并在两种渲染器上使用同一规则结果。

### 8.2 反馈层级

| 事件 | 首版反馈建议 | 限制 |
| --- | --- | --- |
| 普通咬 | 小幅受击形变、短音效、方向提示 | 多次命中合并，不连续遮挡鱼体 |
| 背刺 | 尾部闪光和“背刺”字样 | 与普通咬明显不同，但不全屏刷字 |
| 反击准备 | 半秒范围轮廓与收缩倒计时 | 显示在伤害发生之前 |
| 吞噬 | 短粒子爆开、清脆音效、可选短顿帧 | 顿帧作为表现效果，不延长无敌或改变结算 |
| 羁绊 | 专用图标、短电弧和触发提示 | 不逐目标震屏，不递归播音 |
| 缩圈 | 地图边缘、下一圈位置和倒计时 | 危险区不盖过身体或技能预告 |
| 淘汰 | 来源与技能提示、名次更新 | 死亡、胜利和奖励只播一次 |

提供关闭震动、降低粒子、静音和减少闪烁选项。联机时顿帧只影响本地表现，权威逻辑继续运行；单人也须保持时钟、伤害和冷却的统一口径。

首版结算建议展示名次、有效游玩时间、竞技分、四个突变、一次关键组合、最后伤害来源和“一键重开”。击杀回放后续再做；近期伤害摘要不能冒称完整回放。

## 9. 模式、长期成长与商业化路线

| 用户提出的方向 | 建议顺序 | 启动前提 |
| --- | --- | --- |
| 大逃杀 | 首版用 AI 做本地短局缩圈原型 | 胜负、成长和反杀闭环成立 |
| 无尽生存 | 在现有无限海域另定义正式生存规则 | 明确是否禁复活、击杀 BOSS 是否继续、分数口径 |
| 1v1 排位 | 先本地／房间对战原型，后正式排位 | 同步与权威裁决成立；纯操作目标与随机突变如何兼容须明确 |
| 3v3 团队吞噬 | 先选抢肉、护卵、占点中的一个目标 | 团队身份、视野、死亡与复活、队伍平衡可解释 |
| Boss 合作 | 一个 Boss、一个可打断技能、一种协作目标 | 真人协作与网络成立；不能用多个 AI 围攻替代配合验证 |
| 自定义／UGC | 先有限模板地图编辑，再规则编辑 | 地图合法性、预算、版本、分享与内容治理明确 |
| 图鉴与进化树 | 短局稳定后补收藏、行为观察和纯外观解锁 | 与已有成就／收藏存储的职责一致 |
| 赛季海域 | 珊瑚城 → 深海遗迹 → 冰海／火山逐个试验 | 每主题提供一项新决策，不只改颜色 |
| 公会、快捷表情、复仇提醒、连杀播报 | 社交阶段逐项验证 | 有真实多人场景；播报不过度遮挡操作 |
| 皮肤、通行证 | 有持续用户需求后再评估 | 账户、权益、售后及平台接入完成；不出售战斗数值 |

长期成长建议保存收藏、成就、外观、熟练度与赛季纪录，不把长期付费或刷局时长转换成短局初始伤害、体型与技能等级。皮肤可以改变外观和特效，但危险预告与碰撞口径一致。

“秒匹配、AI 补位、断线重连”是联机服务目标。当前项目纯前端本地运行，尚没有这些服务；匹配时长与低端机流畅度都要用实际部署和设备测试记录验证。

## 10. 工程接入与防止规则分叉

现有实现已拆分数据、系统、状态工厂、HUD 与双渲染，可按职责接入。下表是位置建议，不表示本次修改了这些文件。

| 工作 | 建议接入点 | 必须守住的边界 |
| --- | --- | --- |
| 模式入口与初始化 | `src/data/runRules.ts`、`src/factories/initialState.ts`、`src/App.tsx` | 显式新模式；旧存档和默认开局保持可读 |
| 参赛者与状态 | `src/types.ts`、实体工厂、AI 系统 | 参赛者／中立身份独立；同鱼种敌人也可交战 |
| 缩圈与时限 | 新的独立对局系统，注册到 `src/systems/index.ts` | 单一有效时钟；同帧结算、暂停和结束优先级固定 |
| 战斗与效果 | `combat.ts`、`skills.ts`、状态计时入口 | 玩家／AI、公用／特殊技能统一过滤、计时与来源 |
| 突变与选择 | 独立突变数据与结算模块、`progression.ts`、选择 UI | 候选固定、交易一次、属性从基础值重算不反复相乘 |
| 地图与资源 | 地形、洋流、事件与生成系统 | 有限预算、合法位置、参赛者公平可达 |
| 风险与反馈 | 共用规则结果、`UIOverlay.tsx`、Canvas／Pixi | 渲染读取判定，不各自实现一套可吞规则 |
| 排行与记录 | `leaderboard.ts`、本地存储 | 模式与规则版本隔离，练习不进入正式榜 |

公平性修正应先收口目标过滤、伤害归属、状态递减与一次死亡结算。当前附录已记录 AI 范围技能漏掉玩家、部分状态计时不一致和吸能来源缺失等问题；这些问题会直接影响竞技判断，不能用新增特效掩盖。

未来联网建议以服务端权威输入与结算为边界；客户端预测、校正、断线重连窗口、掉线代打与排名资格需另行规格。局内随机要有可追溯的种子和规则版本，但种子本身不等于防作弊或完整可重放。

## 11. 分阶段落地与验收

每阶段先完成一个能运行的闭环，再扩大内容。以下为建议批次；用户确认实现范围后再写入现有唯一任务清单。

| 批次 | 可试玩结果 | 必要验证 |
| --- | --- | --- |
| A：公平规则 | 同种敌人可交战，玩家与 AI 同规则受击、状态和死亡 | 方向、护盾、无敌、越级、持续伤害来源与一次奖励 |
| B：四分钟对局 | 固定开局、六参赛者、缩圈、明确结算、一键重开 | 不提前被旧 BOSS 胜利结束；同帧死亡；240 秒结束；练习与旧模式隔离 |
| C：代表构筑 | 先提供机动、毒控、防护三套预设 | 同种子、同资源、不同构筑能产生可描述打法差异 |
| D：随机与羁绊 | 九突变、四选择、一个毒电组合、一个逆袭秘宝 | 候选合法、跨级排队、无重复领取、无递归、落后条件可解释 |
| E：信息与地图 | 急停、预告、水草／窄缝／洋流、两个秘宝窗口 | 至少一次靠操作改变结果；危色与判定一致；关键点可达 |
| F：真人与性能 | 基于试玩记录调整，明确首版放行结论 | 体验证据、同设备基线、长时间重开、双渲染一致 |

初步体验验收建议：至少 5 位首次接触玩家，各体验两种构筑并完成或退出多局；记录种子、选择、事件参与、死因、胜负和主动时间。分别统计完整局、提前失败局与暂停用时。观察多数玩家能否解释死亡原因、识别一个组合、指出一次有意义的取舍；不把“操作很多”当作操作有深度。

性能验收先指定设备、浏览器、分辨率和渲染器，再提出门槛。目标为 60 帧体验；记录帧时间 p95、长帧数量、逻辑／渲染耗时和资源趋势。首版为参赛者、野鱼、食物、粒子、飘字分别设置上限；用四分钟自然局和连续重开检验，拥挤决赛圈也要测。现有性能记录不等于新模式或所有低端机达标。

自动测试覆盖确定性与规则，真人试玩验证可读性与乐趣。只改设计文档不需要重跑游戏测试；实现阶段再按实际改动完成相关单测、端到端、类型检查和构建。

## 12. 关键取舍与待确认项

| 问题 | 草案采用的建议 | 对设计的影响 |
| --- | --- | --- |
| 主打短局还是保留长局争霸定位 | 新增短局实验，保留现有长局 | 避免同时改变局长、队伍与整个任务系统 |
| 首版是否真人联机 | 本地 AI 原型优先 | 先验证规则，社交与匹配体验留到联机阶段 |
| 首版是否保留附身 | 暂不在短局启用 | 后续可独立做团队或多生命变体 |
| 自由加点还是三选一 | 先三选一，点数拆分后再考虑自由分配 | 降低首次学习负担，仍有构筑决策 |
| 四分钟到时怎样结束 | 存活者按竞技分，再看有效伤害，可并列 | 必须在 HUD 显示计分与名次目标 |
| 初始鱼种与局外属性 | 固定低阶，同属性开局 | 防止现有 T3 和存储技能等级带来优势 |
| 触摸设备 | 桌面先验证，移动输入单独设计 | 当前没有完整触摸摇杆与多技能输入方案 |

用户的一局示例可以作为最终体验目标：小鱼吃食物 → 选择毒牙 → 争夺电鳍 → 借绕后触发组合 → 用水草脱离追击 → 缩圈中赶赴决赛区 → 用冲刺窗口淘汰对手 → 看到组合、操作与名次结算。它包含明确的决定和应对窗口，适合用作原型验收脚本；尚不能视为当前游戏已经可走通的流程。
